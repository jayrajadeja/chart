# chart serve — implementation plan

Spec: [`../specs/2026-09-29-serve-design.md`](../specs/2026-09-29-serve-design.md).
TDD, minimal surgical diffs, gate green after every task. Standard library only.

## Task 1 — `upstream.Source` + `HTTPSource`
- **Test first** `upstream/http_test.go`: against `httptest.Server` returning candle
  JSON — decodes to `[]chart.Candle`; forwards symbol/width/from/to; upstream non-200
  -> error; malformed JSON -> error; unreachable base URL -> error.
- **Implement** `upstream/http.go`: `Source` interface; `HTTPSource{base, client}`,
  `NewHTTP(base, client)`; `Candles` builds the query, GETs `/v1/candles`, decodes
  `{candles:[{start,open,high,low,close,...}]}` into `[]chart.Candle`.
- Gate.

## Task 2 — `chart/server` handler
- **Test first** `server/handler_test.go`: fake Source; healthz; happy path (axis +
  glyphs + footer); missing symbol / width<=0 / height<=0 -> 400; empty -> 200
  `(no candles)`; source error -> 502; non-GET -> 405; unknown path -> 404;
  `updown=false`.
- **Implement** `server/handler.go`: `Handler(src upstream.Source, def Defaults)`;
  `/healthz`, `/v1/chart`, catch-all 404; param parsing/validation; render via
  `chart.Render`; `text/plain`; `writeText`/`writeErr` helpers.
- Gate.

## Task 3 — `serve` subcommand
- **Test first** `cmd/chart/serve_test.go`: ephemeral-port smoke with a fake upstream
  `httptest.Server`; `/healthz` + `/v1/chart` return expected bodies; clean shutdown.
- **Implement** `cmd/chart/serve.go`: `runServeCmd` (flags `--addr` default
  `127.0.0.1:8139`, `--candles-url` default `http://127.0.0.1:8138`, `--height`,
  `--updown`) + `runServe(addr, src, def, ctx, ready)`; `main` dispatches `serve`.
- Gate.

## Task 4 — docs
- README: serve section (endpoint table, flags, the proxy/compose note); layout rows
  for `upstream/`, `server/`.
- AGENTS: one line — serve is a rendering proxy over candle serve's JSON; no
  aggregation/storage in chart; the renderer stays pure.

## Task 5 — gate + review + PR
- Full gate + manual e2e (`candle serve` upstream, `chart serve` proxy, curl parity
  vs `... | candle --csv | chart`).
- Fresh code-review agent (focus: upstream error->502 mapping, param validation order,
  empty->200, JSON decode robustness, client timeout, graceful shutdown, no data race).
- Fix Critical/Important. Open PR base main via `as-personal gh pr create`, disclose
  model + plugins. Never self-merge.
