# chart — implementation plan

Spec: [`../specs/2026-09-29-chart-design.md`](../specs/2026-09-29-chart-design.md).
TDD, minimal surgical diffs, gate green after every task. Standard library only.

## Task 1 — `chart` pure renderer
- **Test first** `chart/chart_test.go`: bad height -> `ErrBadHeight`; empty ->
  `ErrNoCandles`; single-candle exact per-row glyphs; up/down glyphs (with/without
  `--updown`); flat range; footer contents; row count + width invariants.
- **Implement** `chart/chart.go`: `Candle`, `Options`, `Render`, integer `rowOf`/
  `priceAt`, `cell` (body-over-wick), `footer`; `chart/format.go` helpers
  (`itoa`/`numWidth`/`padLeft`/`spaces`).
- Gate.

## Task 2 — `parse` CSV reader
- **Test first** `parse/parse_test.go`: happy path, reordered + extra columns,
  empty, header-only, missing column, non-numeric field, `high < low`.
- **Implement** `parse/parse.go`: `ReadCSV` via `encoding/csv`, columns bound by
  header name, ragged rows tolerated, `high >= low` validation.
- Gate.

## Task 3 — `cmd/chart` CLI
- **Test first** `cmd/chart/main_test.go`: `run` over stdin + file arg, bad height,
  empty input, missing file, bad flag (exit codes 0/1/2).
- **Implement** `cmd/chart/main.go`: `run` seam, `--height`/`--updown`, stdin/file,
  wire `parse` -> `chart`, print lines; `main` -> `os.Exit(run(...))`.
- Gate.

## Task 4 — repo hygiene + docs
